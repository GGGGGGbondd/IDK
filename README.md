# 记忆世界 V2 — 完整微缩环境版

## 开始使用

### 单人体验（最快）

解压项目后，打开 `public/index.html`。推荐 Chrome 或 Edge。单人场景操作和记忆保存无需服务器。

### 开启双人局域网共创

安装 Node.js 18+，在本文件夹运行：

```bash
npm install
npm start
```

电脑浏览器访问 `http://localhost:3000`。同一 Wi-Fi 中的第二台设备访问 `http://电脑局域网IP:3000`，输入第一台电脑展示的六位世界码。

若局域网无法连接，检查 Windows 防火墙是否允许 Node.js 使用 3000 端口。

## 主要功能

- 多世界首页；5 种完整主题环境；岛屿章节管理
- 微缩立体树木、房屋、座椅、路灯、帐篷等场景模型
- 家具和纪念物件添加、拖拽调整、网格吸附、移除
- 记忆文字、照片、音频、视频上传与本机 IndexedDB 保存
- 自己绘制一张小画绑定到记忆物件
- 两件纪念物件间的共鸣连线；访客探索模式
- WebSocket 实时广播、世界邀请码和在线人数

## 已知边界

- 场景为 2D Canvas 等距渲染，并非可自由旋转镜头的真实 3D 世界。
- 自绘图片以本地照片附件方式保存，不自动变成 3D 模型。
- 上传素材仅存储在本机 IndexedDB，共创伙伴无法直接查看他人原始媒体。
- 服务器世界状态只存于运行时内存。服务器重启后，客户端自己的本地世界仍在；非客户端保存的远程世界状态不可保证恢复。
- 共创采用简单的全世界广播，快速并发编辑可能出现后写覆盖，不适合作为公网正式产品。
- 现场演示前请至少在两台设备上自测。
